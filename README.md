# Змейка - Классическая игра

Классическая игра "Змейка" на HTML5 Canvas с красивым дизайном и простым управлением.

## Описание

Управляйте змейкой, собирайте еду и растите! Не врезайтесь в стены или в себя.

## Особенности

- Красивый современный дизайн с градиентами
- Адаптивный интерфейс
- Счетчик очков и рекордов
- Сохранение рекорда в localStorage
- Анимированная змейка с глазами
- Пауза и рестарт игры
- Управление стрелками или WASD

## Как играть

1. Откройте файл `index.html` в браузере
2. Нажмите кнопку "Начать игру"
3. Управляйте змейкой:
   - **Стрелки** (← ↑ → ↓) или **WASD**
   - **Пробел** - пауза

## Правила

- Собирайте красную еду, чтобы расти
- За каждую еду +10 очков
- Не врезайтесь в стены
- Не врезайтесь в свое тело
- Ваш рекорд сохраняется автоматически

## Технологии

- HTML5
- CSS3 (градиенты, анимации, blur эффекты)
- JavaScript (Canvas API)
- LocalStorage для сохранения рекорда

## Демо

Просто откройте `index.html` в любом современном браузере!
