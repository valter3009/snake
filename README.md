# 🤖 Автоматический Telegram Новостной Бот

Полностью автоматический бот для публикации новостей в Telegram канал с использованием ИИ для генерации привлекательных текстов.

## 📋 Возможности

- ✅ **Автоматический парсинг** 7 качественных русскоязычных новостных источников
- ✅ **Извлечение медиа** - реальные фото из новостей (не генерация ИИ)
- ✅ **AI-обработка текстов** через Claude API для создания привлекательных постов
- ✅ **Автоматическая публикация** 8 раз в день по расписанию
- ✅ **База данных** для отслеживания опубликованных новостей
- ✅ **Подробное логирование** всех операций
- ✅ **Защита от дубликатов** - проверка уже опубликованных новостей

## 🚀 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <project-directory>
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Создание Telegram бота

1. Найдите бота [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Сохраните токен - он понадобится для настройки

### 4. Создание Telegram канала

1. Создайте новый канал в Telegram
2. Добавьте созданного бота в администраторы канала
3. Дайте боту права на публикацию сообщений
4. Получите ID канала:
   - Если канал публичный: используйте `@channel_username`
   - Если приватный: используйте числовой ID (например, `-1001234567890`)

### 5. Получение Claude API ключа

1. Зарегистрируйтесь на [Anthropic Console](https://console.anthropic.com/)
2. Перейдите в раздел API Keys
3. Создайте новый API ключ
4. Сохраните ключ - он понадобится для настройки

### 6. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```bash
# Telegram настройки
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHANNEL_ID=@your_channel_or_chat_id

# Claude API
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

**Пример:**
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHANNEL_ID=@mynewschannel
ANTHROPIC_API_KEY=sk-ant-api03-xxx
```

## 🎯 Использование

### Тестовый запуск

Перед полноценным запуском рекомендуется протестировать бота:

```bash
python main.py --test
```

Эта команда:
- Проверит подключения к Telegram и Claude API
- Спарсит новости из всех источников
- Сгенерирует и опубликует один тестовый пост

### Запуск в обычном режиме

```bash
python main.py
```

Бот будет работать по расписанию и публиковать посты в:
- 08:00, 10:00, 12:00, 14:00, 16:00, 18:00, 20:00, 22:00 (московское время)

### Запуск как демон (Linux/MacOS)

Используйте `nohup` для запуска в фоновом режиме:

```bash
nohup python main.py > output.log 2>&1 &
```

Или создайте systemd сервис:

```ini
[Unit]
Description=Telegram News Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/project
ExecStart=/usr/bin/python3 /path/to/project/main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Сохраните как `/etc/systemd/system/newsbot.service` и запустите:

```bash
sudo systemctl daemon-reload
sudo systemctl enable newsbot
sudo systemctl start newsbot
```

## 📊 База данных

Бот использует SQLite для хранения:

- **published_news** - опубликованные новости
- **statistics** - статистика публикаций

База данных создается автоматически при первом запуске в файле `news_database.db`.

### Очистка базы данных

Старые записи (старше 30 дней) автоматически удаляются каждый день в 03:00.

## 📝 Логирование

Все операции логируются в:
- **Консоль** - для мониторинга в реальном времени
- **news_bot.log** - файл с полной историей

Уровень логирования можно изменить в `config.py`:

```python
LOG_LEVEL = 'INFO'  # DEBUG, INFO, WARNING, ERROR
```

## 🛠 Устранение неполадок

### Проблема: Бот не публикует посты

1. Проверьте, что бот добавлен в канал как администратор
2. Проверьте права бота в канале (должна быть возможность публикации)
3. Убедитесь, что `TELEGRAM_CHANNEL_ID` указан правильно
4. Проверьте логи на наличие ошибок

### Проблема: Не загружаются изображения

1. Некоторые сайты блокируют автоматическую загрузку
2. Изображения могут не соответствовать минимальным требованиям
3. Проверьте интернет-соединение
4. Бот автоматически публикует только текст, если изображение недоступно

### Проблема: Ошибки Claude API

1. Проверьте баланс на аккаунте Anthropic
2. Убедитесь, что API ключ валидный
3. Проверьте лимиты использования API

### Проблема: Дубликаты новостей

1. База данных отслеживает опубликованные новости
2. Если база была удалена, дубликаты могут появиться
3. Проверьте наличие файла `news_database.db`
