# IDTrade - Криптовалютный торговый бот

Автоматизированный торговый бот для криптовалютной биржи MEXC с веб-интерфейсом для мониторинга.

## Основные возможности

- **Торговая стратегия**: RSI + Moving Average
- **Режим симуляции**: Тестирование без реальных денег (Paper Trading)
- **Веб-интерфейс**: Удобный dashboard для мониторинга
- **База данных**: Хранение истории сделок и сигналов
- **Логирование**: Подробное логирование всех операций
- **Управление рисками**: Настраиваемые stop-loss и take-profit

## Технический стек

- **Python 3.10+**
- **ccxt** - работа с криптобиржами
- **pandas, numpy** - анализ данных
- **Flask** - веб-интерфейс
- **SQLite** - хранение данных
- **asyncio** - асинхронная работа

## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/valter3009/snake.git
cd snake
```

### 2. Создание виртуального окружения

```bash
python -m venv venv

# Linux/Mac
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации

Скопируйте `.env.example` в `.env` и настройте параметры:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# API ключи MEXC (для реального режима)
MEXC_API_KEY=your_api_key_here
MEXC_API_SECRET=your_api_secret_here

# Режим работы
TRADING_MODE=simulation  # simulation или live

# Торговая пара
TRADING_PAIR=BTC/USDT

# Начальный баланс для симуляции
INITIAL_BALANCE=1000.0
```

### 5. Настройка стратегии

Отредактируйте `bot/config/config.yaml`:

```yaml
strategy:
  name: rsi_ma
  rsi:
    period: 14
    oversold: 30      # Уровень перепроданности
    overbought: 70    # Уровень перекупленности
  ma:
    short_period: 20  # Короткая скользящая средняя
    long_period: 50   # Длинная скользящая средняя
```

## Торговая стратегия

### RSI + Moving Average

Стратегия использует комбинацию двух популярных индикаторов:

#### Сигнал на ПОКУПКУ (BUY):
- RSI < 30 (уровень перепроданности)
- Короткая MA > Длинная MA (восходящий тренд)

#### Сигнал на ПРОДАЖУ (SELL):
- RSI > 70 (уровень перекупленности)
- Короткая MA < Длинная MA (нисходящий тренд)

#### Управление позицией:
- **Stop Loss**: 2% от цены входа (настраивается)
- **Take Profit**: 5% от цены входа (настраивается)
- Автоматическое закрытие при достижении уровней

## Управление рисками

```yaml
risk_management:
  max_position_size: 0.1      # Максимум 10% баланса на сделку
  stop_loss_percent: 2.0      # Стоп-лосс 2%
  take_profit_percent: 5.0    # Тейк-профит 5%
  max_daily_trades: 10        # Максимум 10 сделок в день
  max_open_positions: 3       # Максимум 3 открытых позиции
```

## Режим симуляции (Paper Trading)

По умолчанию бот работает в режиме симуляции:

- Использует **реальные рыночные данные** с биржи
- Совершает **виртуальные сделки** без реальных денег
- Эмулирует комиссии биржи (0.1%)
- Идеально для тестирования стратегий

## Переход на реальную торговлю

⚠️ **ИСПОЛЬЗУЙТЕ С ОСТОРОЖНОСТЬЮ**

1. Получите API ключи на [MEXC](https://www.mexc.com/)
2. Добавьте ключи в `.env`
3. Измените режим в `config.yaml`:
   ```yaml
   trading:
     mode: live  # Реальный режим
   ```
4. Запустите бота с минимальным балансом для тестирования

## Разработка новых стратегий

Создайте класс, наследующий `BaseStrategy`:

```python
from bot.strategies.base_strategy import BaseStrategy

class MyStrategy(BaseStrategy):
    def __init__(self):
        super().__init__(name="MyStrategy")

    def analyze(self, data):
        # Ваша логика анализа
        return {
            'signal': 'buy',  # buy, sell, hold
            'reason': 'Описание причины',
            'confidence': 0.8,
            'indicators': {}
        }

    def get_position_size(self, balance, price, risk_percent):
        return balance * risk_percent / price
```

## FAQ

**Q: Бот безопасен для реальной торговли?**
A: Бот предназначен для образовательных целей. Используйте реальный режим на свой страх и риск.

**Q: Какие биржи поддерживаются?**
A: В данный момент только MEXC, но легко адаптируется под другие биржи через ccxt.

**Q: Как изменить торговую пару?**
A: Измените параметр `pairs` в `config.yaml`.

**Q: Можно ли торговать несколько пар одновременно?**
A: Да, добавьте несколько пар в конфигурацию:
```yaml
trading:
  pairs:
    - BTC/USDT
    - ETH/USDT
    - BNB/USDT
```
