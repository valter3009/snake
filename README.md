# 🤖 Автоматический Telegram Новостной Бот с Модерацией

Полностью автоматический бот для публикации новостей в Telegram канал с использованием Claude AI для анализа важности, генерации постов и модерацией перед публикацией.

## 📋 Возможности

- ✅ **Автоматический сбор новостей** из NewsAPI и RSS-лент (РБК, ТАСС, Коммерсантъ)
- ✅ **AI-анализ важности** новостей через Claude API
- ✅ **Интеллектуальная группировка дубликатов** - объединение новостей об одном событии
- ✅ **AI-генерация постов** с разными форматами и стилями (не шаблонно!)
- ✅ **Модерация постов** - админ получает пост с кнопками одобрения/редактирования
- ✅ **Автоматическая публикация** 4-10 постов в день в рандомное время
- ✅ **PostgreSQL база данных** для хранения опубликованных новостей
- ✅ **Обработка медиа** - оптимизация и публикация изображений из новостей
- ✅ **Graceful shutdown** и обработка ошибок

## 🚀 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd <project-directory>
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Создание Telegram бота

1. Найдите бота [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен бота
4. Сохраните токен

### 4. Создание Telegram канала

1. Создайте новый канал в Telegram
2. Добавьте созданного бота в администраторы канала
3. Дайте боту права на публикацию сообщений
4. Получите ID канала:
   - Если канал публичный: используйте `@channel_username`
   - Если приватный: используйте числовой ID (например, `-1001234567890`)

### 5. Получение Telegram ID админа

1. Найдите бота [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте ему любое сообщение
3. Получите ваш ID (число)

### 6. Получение API ключей

#### Claude API (Anthropic)
1. Зарегистрируйтесь на [Anthropic Console](https://console.anthropic.com/)
2. Перейдите в раздел API Keys
3. Создайте новый API ключ

#### NewsAPI
1. Зарегистрируйтесь на [NewsAPI.org](https://newsapi.org/)
2. Получите бесплатный API ключ

### 7. Настройка переменных окружения

Создайте файл `.env` в корне проекта (используйте `.env.example` как шаблон):

```bash
# Telegram настройки
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
TELEGRAM_CHANNEL_ID=@mynewschannel
TELEGRAM_ADMIN_ID=123456789

# API ключи
ANTHROPIC_API_KEY=sk-ant-api03-xxx
NEWS_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# PostgreSQL
DATABASE_URL=postgresql://user:password@localhost:5432/news_bot
```

### 8. Инициализация базы данных

База данных создается автоматически при первом запуске.

Для локальной разработки установите PostgreSQL:

```bash
# Ubuntu/Debian
sudo apt-get install postgresql postgresql-contrib

# MacOS
brew install postgresql
```

Создайте базу данных:

```bash

```

## 🎯 Использование

### Запуск локально

```bash
python -m bot.main
```

### Команды бота (только для админа)

- `/start` - Приветствие и список команд
- `/status` - Статус бота и статистика
- `/publish` - Принудительная публикация новостей

### Модерация постов

Когда бот находит и генерирует пост, он отправляет его админу с кнопками:
- ✅ **Опубликовать** - публикация без изменений
- ✏️ **Редактировать** - отправьте новый текст в ответ на сообщение
- ❌ **Отклонить** - пост не будет опубликован

Если админ не ответит в течение 15 минут, пост публикуется автоматически.

## 📊 База данных

Бот использует PostgreSQL с двумя таблицами:

### published_posts
Хранит опубликованные посты (30 дней):
- id
- url (уникальный)
- title
- published_at
- source

### post_schedule
Статистика публикаций:
- id
- scheduled_time
- published
- post_id
- created_at

Старые записи (>30 дней) автоматически удаляются каждый день.

## 📝 Логика работы

1. **Сбор** - Каждые 30-60 минут (рандом) бот собирает новости
2. **Фильтрация** - Только свежие (<6 часов) и неопубликованные
3. **Анализ** - Claude оценивает важность (1-10) и выбирает топ-3
4. **Группировка** - Похожие новости объединяются (>70% схожесть)
5. **Генерация** - Claude создает уникальные посты в разных форматах
6. **Модерация** - Админ получает пост для одобрения (15 мин таймаут)
7. **Публикация** - Пост публикуется в канал с медиа (если есть)

## 🎨 Форматы постов

Бот использует 5 разных форматов (взвешенный рандом):
- 📰 Классическая новость с заголовком (30%)
- 💬 "Заметил интересное..." (личный стиль) (25%)
- 🔥 "Горячее: ..." (срочные новости) (20%)
- 🤔 "А что думаете о..." (провокация дискуссии) (15%)
- 📊 "Коротко о главном" (дайджест) (10%)

Длина постов также варьируется:
- Короткие (2-3 предложения) - 30%
- Средние (абзац) - 50%
- Длинные (2-3 абзаца) - 20%

## 🛠 Устранение неполадок

### Проблема: Бот не публикует посты

1. Проверьте, что бот добавлен в канал как администратор
2. Проверьте права бота (публикация сообщений)
3. Проверьте `TELEGRAM_CHANNEL_ID` в переменных окружения
4. Проверьте логи Railway или локальные

### Проблема: Ошибки Claude API

1. Проверьте баланс на аккаунте Anthropic
2. Убедитесь, что API ключ валидный
3. Проверьте лимиты использования API (Rate Limits)

### Проблема: Ошибки PostgreSQL

1. Проверьте `DATABASE_URL` в переменных
2. Убедитесь, что база данных создана и доступна
3. На Railway проверьте, что PostgreSQL сервис запущен

### Проблема: Не загружаются изображения

1. Некоторые сайты блокируют автоматическую загрузку
2. Бот автоматически публикует только текст, если изображение недоступно
3. Проверьте интернет-соединение
