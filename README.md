# 🤖 Криптовалютный AI Telegram-бот

> Автоматический Telegram канал с экспертной аналитикой рынка криптовалют на базе искусственного интеллекта Claude

[![Python 3.11+](https://img.shields.io/badge/python-3.11+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 🌟 Особенности

- ✅ **Умная фильтрация**: только важные события (5-8 постов/день вместо 100+)
- ✅ **AI-генерация**: каждое сообщение уникально и написано экспертным языком через Claude API
- ✅ **Публичные API**: не нужны платные ключи (кроме Telegram + Claude)
- ✅ **Автоматизация**: работает 24/7 без вмешательства
- ✅ **Экономично**: всего $2-7/месяц на хостинг и API
- ✅ **Production-ready**: готов к деплою на Railway/Heroku

## 📊 Что публикует бот

- 🌅 **Утренний обзор рынка** (08:00 UTC)

## 🚀 Быстрый старт

### Предварительные требования

- Python 3.11+
- Telegram бот токен (получить у [@BotFather](https://t.me/BotFather))
- Claude API ключ (получить на [console.anthropic.com](https://console.anthropic.com/))
- Telegram канал

### Установка

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/yourusername/crypto-telegram-bot.git
cd crypto-telegram-bot
```

2. **Создайте виртуальное окружение:**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Настройте переменные окружения:**
```bash
cp .env.example .env
# Отредактируйте .env и заполните:
# - TELEGRAM_BOT_TOKEN
# - TELEGRAM_CHANNEL_ID
# - ANTHROPIC_API_KEY
```

5. **Запустите бота:**
```bash
python src/main.py
```

## 📝 Настройка

### Обязательные переменные окружения

```env
# Telegram Bot (получить у @BotFather)
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHANNEL_ID=@your_channel

# Claude API (получить на console.anthropic.com)
ANTHROPIC_API_KEY=sk-ant-your_key_here
```

### Опциональные настройки фильтрации

```env
# Минимальная сумма транзакции кита (USD)
MIN_WHALE_AMOUNT=5000000

# Минимальная капитализация для листинга (USD)
MIN_LISTING_MARKET_CAP=100000000

# Минимальная оценка важности (0-10)
MIN_IMPORTANCE_SCORE=7

# Лимиты публикаций
MAX_MESSAGES_PER_HOUR=3
MAX_MESSAGES_PER_DAY=12
```

Полный список настроек смотрите в `.env.example`

## 🌐 Деплой на Railway

1. **Создайте аккаунт на [Railway.app](https://railway.app/)**

2. **Подключите репозиторий:**
   - New Project → Deploy from GitHub repo
   - Выберите ваш форк репозитория

3. **Добавьте переменные окружения:**
   - В настройках проекта → Variables
   - Добавьте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`, `ANTHROPIC_API_KEY`

4. **Добавьте PostgreSQL (опционально, для production):**
   - New → Database → PostgreSQL
   - Railway автоматически создаст `DATABASE_URL`

5. **Деплой!**
   - Railway автоматически развернет бота
   - Логи доступны в реальном времени

## 💰 Стоимость эксплуатации

### Claude API:
- **Модель**: Claude Sonnet 4
- **Цены**: $3/1M input tokens, $15/1M output tokens
- **Примерно**: $0.01 за сообщение
- **7 сообщений/день × 30 дней**: ~$2-3/месяц

### Railway Hosting:
- **Free tier**: $5 кредитов/месяц (обычно достаточно)
- **Starter**: $5/месяц (если превысили free tier)

### Публичные API:
- **CoinGecko**: Бесплатно (10-50 req/min)
- **Alternative.me**: Бесплатно (без лимитов)
- **Binance/Coinbase**: Бесплатные публичные API

**ИТОГО: $2-8/месяц** 💰

## 🧠 Система оценки важности

Каждое событие оценивается по шкале 0-10 на основе:

- **Размер/масштаб** (30%): сумма транзакции, капитализация проекта
- **Влияние на рынок** (25%): исторические данные, биржа
- **Популярность актива** (20%): BTC, ETH важнее альткоинов
- **Новизна информации** (15%): уникальность события
- **Контекст рынка** (10%): время суток, волатильность

**Публикуются только события с оценкой ≥ 7**
