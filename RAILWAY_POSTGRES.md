# 🚨 ВАЖНО: Добавление PostgreSQL в Railway

## ❌ Текущая проблема

```
ERROR - Отсутствуют обязательные переменные окружения: DATABASE_URL
```

Это значит, что **PostgreSQL НЕ ДОБАВЛЕН** в ваш Railway проект!

---

## ✅ Решение: Добавьте PostgreSQL

### Шаг 1: Откройте ваш проект в Railway

1. Зайдите на https://railway.app/
2. Откройте ваш проект со змеёй

### Шаг 2: Добавьте PostgreSQL базу данных

**В интерфейсе проекта:**

```
1. Нажмите кнопку "+ New" (правая верхняя часть или в центре)
2. Выберите "Database"
3. Выберите "Add PostgreSQL"
```

**Визуально это выглядит так:**
```
┌─────────────────────────────────────┐
│  Ваш проект                         │
│                                     │
│  ┌──────────┐                       │
│  │   Bot    │  ← Ваш сервис         │
│  └──────────┘                       │
│                                     │
│  [+ New]  ← Нажмите сюда           │
└─────────────────────────────────────┘

После нажатия "+ New":
┌─────────────────────┐
│ Database            │ ← Выберите это
│ Empty Service       │
│ GitHub Repo         │
│ Docker Image        │
└─────────────────────┘

После выбора Database:
┌─────────────────────┐
│ Add PostgreSQL      │ ← Выберите это
│ Add MySQL           │
│ Add Redis           │
│ Add MongoDB         │
└─────────────────────┘
```

### Шаг 3: Дождитесь создания базы

Railway автоматически:
- ✅ Создаст PostgreSQL сервис
- ✅ Создаст переменную `DATABASE_URL`
- ✅ Свяжет её с вашим Bot сервисом

**Вы увидите:**
```
┌─────────────────────────────────────┐
│  Ваш проект                         │
│                                     │
│  ┌──────────┐    ┌──────────┐      │
│  │   Bot    │────│PostgreSQL│      │
│  └──────────┘    └──────────┘      │
│                      ↑              │
│              DATABASE_URL           │
└─────────────────────────────────────┘
```

### Шаг 4: Проверьте переменные

1. Кликните на **Bot** сервис (НЕ на PostgreSQL)
2. Перейдите в **Variables**
3. Вы должны увидеть **6 переменных**:

```
✅ TELEGRAM_BOT_TOKEN=...
✅ TELEGRAM_CHANNEL_ID=...
✅ TELEGRAM_ADMIN_ID=...
✅ ANTHROPIC_API_KEY=...
✅ NEWS_API_KEY=...
✅ DATABASE_URL=postgresql://... ← Создалась автоматически!
```

## 🔍 Как проверить, что PostgreSQL добавлен?

### В интерфейсе Railway:

**Правильно (PostgreSQL добавлен):**
```
Вы видите ДВА сервиса в проекте:
- Bot (ваше приложение)
- PostgreSQL (база данных)
```

**Неправильно (PostgreSQL НЕ добавлен):**
```
Вы видите ТОЛЬКО ОДИН сервис:
- Bot (ваше приложение)
```

### В Variables вашего Bot сервиса:

**Правильно:**
```
6 переменных, включая DATABASE_URL
```

**Неправильно:**
```
5 переменных, DATABASE_URL отсутствует
```

## ⚠️ Частые ошибки

### Ошибка 1: "Я добавил PostgreSQL, но DATABASE_URL не появилась"

**Причина:** PostgreSQL не связан с Bot сервисом

**Решение:**
1. Кликните на PostgreSQL сервис
2. Перейдите в Variables
3. Найдите DATABASE_URL
4. Справа от неё нажмите "..." → "Add Reference"
5. Выберите ваш Bot сервис

### Ошибка 2: "Я добавил DATABASE_URL вручную"

**Причина:** Railway должен создать её автоматически

**Решение:**
1. Удалите DATABASE_URL из Variables бота
2. Удалите PostgreSQL сервис
3. Добавьте PostgreSQL заново (шаги выше)

### Ошибка 3: "В Variables есть DATABASE_URL, но бот её не видит"

**Причина:** Нужен передеплой

**Решение:**
1. Settings → Redeploy
2. Или измените любую переменную (добавьте пробел и удалите)
