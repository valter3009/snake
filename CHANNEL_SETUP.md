# Настройка канала @InsightAlert

## Изменение названия канала

Чтобы изменить название канала на `@InsightAlert`, выполните следующие шаги:

### 1. Создайте или обновите файл .env

В корневой директории проекта создайте файл `.env` (если его нет) и добавьте/обновите переменную:

```bash
TELEGRAM_CHANNEL_ID=@InsightAlert
```

### 2. Полный пример .env файла

```bash
# Telegram
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_ADMIN_ID=your_telegram_id_here
TELEGRAM_CHANNEL_ID=@InsightAlert

# Claude AI
ANTHROPIC_API_KEY=sk-ant-api03-xxx

# NewsAPI
NEWS_API_KEY=your_newsapi_key_here

# Database
DATABASE_URL=postgresql://user:pass@host:5432/dbname

# Settings
TIMEZONE=Europe/Moscow
LOG_LEVEL=INFO

# Publishing Schedule
MIN_POSTS_PER_DAY=40
MAX_POSTS_PER_DAY=50
PUBLISH_START_HOUR=7
PUBLISH_END_HOUR=23

# Content Settings
TOP_NEWS_COUNT=5
NEWS_MAX_AGE_HOURS=6
MIN_COLLECTION_INTERVAL=10
MAX_COLLECTION_INTERVAL=20
```

### 3. Настройка Telegram канала

1. Создайте канал в Telegram с именем `@InsightAlert` (или используйте существующий)
2. Добавьте бота в администраторы канала
3. Дайте боту права на публикацию сообщений

### 4. Перезапустите бота

После изменения `.env` файла, перезапустите бота:

```bash
# Если используете Docker
docker-compose restart

# Если запускаете локально
# Остановите бота (Ctrl+C) и запустите заново
python -m bot.main
```

### 5. Проверка

После запуска проверьте логи - бот должен вывести:
```
✅ Конфигурация успешно загружена
📊 Текущая конфигурация:
  • Канал: @InsightAlert
  ...
```

## Формат постов

Бот теперь публикует **короткие новостные посты** в стиле Дмитрия Никотина:

- **Длина**: 50-150 слов (2-3 абзаца максимум)
- **Формат**: Прямо к делу, только ключевые факты
- **Эмодзи**: Используются флаги стран (🇷🇺, 🇺🇸, 🇺🇦, 🇨🇳, 🇪🇺)
- **Стиль**: Простой язык, без длинного анализа

### Примеры постов:

```
🇺🇸 Пит Хегсет лично повесил новую табличку на один из двух
главных входов в ведомство, которое теперь называется Министерство Войны.
```

```
🇩🇪Германия выделяет €150 млн на закупку американского оружия
для 🇺🇦Украины в рамках программы PURL, - министр обороны страны
```

```
🇵🇱Премьер Польши Туск назвал коррупцию возможной причиной
проигрыша Украины в конфликте.

Он отметил, что такие скандалы в будущем осложнят партнерство
Киева с Западом.
```

## Возврат к длинным аналитическим постам

Если вы хотите вернуться к длинным аналитическим постам,
восстановите предыдущую версию файла `bot/content/prompts.py` из git истории.
